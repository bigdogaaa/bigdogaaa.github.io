## 二、基线方法

### 2.1 Baseline 1: Single Judge (Wei et al., 2023)

**核心思想**：单个 LLM 作为评判者

**实现细节**：
```python
class SingleJudge:
    def __init__(self, model="gpt-4-turbo"):
        self.client = OpenAI()
        self.model = model
    
    def judge(self, claim):
        prompt = f"""You are an expert fact-checker. 
        Evaluate whether the following claim is factually accurate.
        
        Claim: {claim}
        
        Provide JSON: {{
          "decision": true/false,
          "confidence": 0.0-1.0,
          "rationale": "brief explanation"
        }}"""
        
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0.0,  # 确定性输出
            max_tokens=200
        )
        
        return parse_json(response)
```

**参数**：
- Model: gpt-4-turbo-2024-04-09
- Temperature: 0.0
- Max tokens: 200

**性能预期**：
- Accuracy: ~85%
- Cost: $0.15/claim
- Latency: ~2s

**成本**：$180 (1,200 claims)  
**时间**：0.5 天

### 2.2 Baseline 2: Self-Consistency (Wang et al., 2022)

**核心思想**：多次采样 + 投票

**实现细节**：
```python
class SelfConsistency:
    def __init__(self, judge, n_samples=5):
        self.judge = judge
        self.n_samples = n_samples
    
    def evaluate(self, claim):
        decisions = []
        confidences = []
        
        for i in range(self.n_samples):
            result = self.judge.judge(claim)
            decisions.append(result['decision'])
            confidences.append(result['confidence'])
        
        # Majority voting
        from collections import Counter
        most_common = Counter(decisions).most_common(1)[0][0]
        
        # Confidence
        majority_mask = [d == most_common for d in decisions]
        avg_confidence = sum(confidences[i] for i, m in enumerate(majority_mask) if m) / sum(majority_mask)
        
        return {
            'decision': most_common,
            'confidence': avg_confidence,
            'consistency_rate': sum(majority_mask) / len(decisions)
        }
```

**参数**：
- n_samples: 5 (默认)
- Temperature: 0.7 (采样多样性)

**Ablation 值**：n=3, n=5, n=10

**性能预期**：
- Accuracy: ~88%
- Cost: $0.75/claim (5 倍采样)
- Latency: ~10s

**成本**：$900 (1,200 × 5)  
**时间**：3 天

### 2.3 Baseline 3: Multi-Agent Debate (DebateLLM, 2024)

**核心思想**：多智能体辩论

**实现细节**：
```python
class MultiAgentDebate:
    def __init__(self, n_agents=3, n_rounds=3):
        self.n_agents = n_agents
        self.n_rounds = n_rounds
        self.agents = [SingleJudge() for _ in range(n_agents)]
    
    def run(self, claim):
        all_votes = []
        
        # Round 1: Independent evaluation
        for agent in self.agents:
            result = agent.judge(claim)
            all_votes.append(result)
        
        # Rounds 2-N: See previous votes
        for round in range(2, self.n_rounds + 1):
            discussion = self._format_discussion(all_votes, round-1)
            for agent in self.agents:
                result = agent.judge(claim, context=discussion)
                all_votes.append(result)
        
        # Majority voting
        return self._aggregate(all_votes)
```

**参数**：
- n_agents: 3 (默认)
- n_rounds: 3 (默认)
- Temperature: 0.3

**Ablation 值**：
- n_agents: 2, 3, 5
- n_rounds: 3, 5, 7

**性能预期**：
- Accuracy: ~95%
- Cost: $1.50/claim (3 agents × 3 rounds)
- Latency: ~15s

**成本**：$1,800 (1,200 × 1.50)  
**时间**：6 天

### 2.4 Baseline 4: Energy-Based Detection (Chen et al., 2026)

**核心思想**：基于能量模型的不确定性检测

**实现细节**：
```python
class EnergyBasedDetector:
    def __init__(self, model):
        """需要访问模型内部状态"""
        self.model = model
    
    def detect(self, claim):
        response = self.model.generate(claim, return_logprobs=True)
        
        # Compute spilled energy
        logprobs = response.logprobs
        energies = [-logprob for logprob in logprobs]
        
        spilled = sum(abs(energies[t] - energies[t-1]) for t in range(1, len(energies)))
        avg_spilled = spilled / len(energies)
        
        # Convert to uncertainty
        uncertainty = 1 / (1 + np.exp(-2 * (avg_spilled - 0.5)))
        
        return {
            'decision': uncertainty < 0.5,
            'confidence': 1 - uncertainty,
            'spilled_energy': avg_spilled
        }
```

**参数**：
- Temperature: 0.0
- 需要模型内部状态访问

**实现挑战**：
- 需要本地部署或支持 internal state 的 API
- 如果无法实现，使用 QueryBandits 作为替代

**成本**：$180 (需要内部状态，如无法获取则跳过)  
**时间**：1 天

### 2.5 Baseline 5: UGMAF (Ours)

**核心思想**：不确定性门控多智能体框架

**实现细节**：
```python
class UGMAF:
    def __init__(self, threshold=0.5):
        self.single = SingleJudge()
        self.multi = MultiAgentDebate()
        self.threshold = threshold
    
    def evaluate(self, claim):
        # Stage 1: Single agent (cheap)
        single_result = self.single.judge(claim)
        
        # Stage 2: Estimate uncertainty
        uncertainty = self._estimate_uncertainty(claim)
        
        # Stage 3: Gated routing
        if uncertainty < self.threshold:
            # Fast path
            return {**single_result, 'method': 'ugmaf_single'}
        else:
            # Robust path
            multi_result = self.multi.run(claim)
            return {**multi_result, 'method': 'ugmaf_multi'}
    
    def _estimate_uncertainty(self, claim):
        entropy = self._compute_entropy(claim)
        consistency = self._compute_consistency(claim)
        energy = self._compute_energy(claim)
        
        # Weighted ensemble
        return 0.4*entropy + 0.4*consistency + 0.2*energy
```

**成本**：$420 (预期平均 $0.35/claim)  
**时间**：4 天

## 三、评估指标

### 3.1 主要指标

**1. Accuracy (准确率)**
```python
def accuracy(y_pred, y_true):
    """Binary classification accuracy"""
    return np.mean(np.array(y_pred) == np.array(y_true))
```

**2. F1-Score (F1 分数)**
```python
from sklearn.metrics import f1_score

def f1_score(y_pred, y_true):
    """Balanced F1 for class imbalance"""
    return f1_score(y_true, y_pred)
```

**3. AUROC (AUC-ROC)**
```python
from sklearn.metrics import roc_auc_score

def auroc(y_scores, y_true):
    """For uncertainty-accuracy correlation"""
    return roc_auc_score(y_true, y_scores)
```

### 3.2 次要指标

**4. Cost (API 调用成本)**
```python
def calculate_cost(method_name, n_claims):
    """计算成本"""
    costs = {
        'single': 0.15,
        'self_consistency': 0.75,
        'multi_agent': 1.50,
        'ugmaf': 0.35  # 预期
    }
    return costs[method_name] * n_claims
```

**5. Latency (延迟)**
```python
# P50, P95, P99
def latency_stats(latencies):
    return {
        'P50': np.percentile(latencies, 50),
        'P95': np.percentile(latencies, 95),
        'P99': np.percentile(latencies, 99),
        'mean': np.mean(latencies)
    }
```

**6. Explainability Score (可解释性评分)**
```python
def explainability_score(debate_log):
    """基于辩论日志的可解释性评分"""
    # Factor 1: Evidence coverage (0-1)
    evidence_score = cited_evidence / required_evidence
    
    # Factor 2: Reasoning depth (0-1)
    reasoning_score = avg_reasoning_depth / max_depth
    
    # Factor 3: Decision transparency (0-1)
    transparency_score = 1 if decision_trace_complete else 0
    
    return 0.4*evidence_score + 0.4*reasoning_score + 0.2*transparency_score
```

### 3.3 统计检验

**1. Paired t-test**
```python
from scipy.stats import ttest_rel

def ttest_accuracy(method1_preds, method2_preds):
    """比较两种方法的准确率"""
    t_stat, p_value = ttest_rel(method1_preds, method2_preds)
    return {'t_statistic': t_stat, 'p_value': p_value}
```

**2. Wilcoxon Signed-Rank Test** (非参数)
```python
from scipy.stats import wilcoxon

def wilcoxon_test(method1, method2):
    """Wilcoxon 检验"""
    stat, p_value = wilcoxon(method1, method2)
    return {'statistic': stat, 'p_value': p_value}
```

**3. Pearson Correlation**
```python
from scipy.stats import pearsonr

def correlation(uncertainty_scores, errors):
    """不确定性 - 准确率相关性"""
    r, p_value = pearsonr(uncertainty_scores, errors)
    return {'correlation': r, 'p_value': p_value}
```
